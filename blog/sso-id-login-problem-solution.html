SSO ID Login नहीं हो रहा? 8 कारण और समाधान (Rajasthan SSO 2026)

✍️ Raj SSO Team 📅 अपडेट: 21/11/2026

SSO लॉगिन फेल होने के ज्यादातर कारण छोटे होते हैं। ऊपर से नीचे इन्हें एक-एक करके जांचें।

8 आम कारण और समाधान

  1. गलत SSO ID या पासवर्ड: Case Sensitive है। ID याद न हो तो ID रिकवर करें।
  2. कैप्चा गलत: कैप्चा रीफ्रेश करके दोबारा भरें।
  3. OTP नहीं आ रहा: नेटवर्क जांचें, 2-3 मिनट रुककर दोबारा मंगाएं। नंबर बदल गया हो तो जन आधार/ई-मित्र से अपडेट कराएं।
  4. Password Expired: Continue दबाकर OTP से नया पासवर्ड बनाएं।
  5. ID लॉक हो गई: कुछ देर रुकें या Forgot Password से रीसेट करें।
  6. सर्वर व्यस्त: भीड़ वाले समय में पोर्टल धीमा हो सकता है। सुबह जल्दी या रात में आजमाएं।
  7. ब्राउज़र कैश: कैश/कुकीज़ साफ करें या दूसरा ब्राउज़र/इनकॉग्निटो आजमाएं।
  8. दो SSO ID: गलत ID से लॉगिन हो सकता है। मर्ज गाइड देखें।

फिर भी समाधान न मिले तो

SSO हेल्पलाइन 0141-5123717 पर कॉल करें या helpdesk.sso@rajasthan.gov.in पर ईमेल करें। SMS से ID पाने के लिए रजिस्टर्ड मोबाइल से RJ SSO लिखकर 9223166166 पर भेजें।

अक्सर पूछे जाने वाले प्रश्न (FAQ)

SSO ID लॉगिन पर Invalid Credentials क्यों दिखता है?

आम तौर पर ID या पासवर्ड गलत होता है, या आप दूसरी SSO ID से लॉगिन कर रहे होते हैं। पासवर्ड रीसेट करके दोबारा कोशिश करें।

क्या SSO लॉगिन के लिए पैसे लगते हैं?

नहीं, लॉगिन और ID बनाना फ्री है।
